# Reading List App

A simple, responsive Reading List web application designed for students to organize their books and track their reading progress.

## Features

- **Add Books:** Add books to your reading list with a title and reading status.
- **Manage Reading Status:** Choose between Want to Read, Reading, and Finished.
- **Filter Books:** Filter your reading list according to reading status.
- **Book Cards:** View books in a clean card-based layout with their titles and current statuses.
- **Empty State:** Displays a helpful message when the reading list is empty.
- **Responsive Design:** Designed to work on desktop and mobile screens.
- **Browser-Based Storage:** Keep reading list data in the browser without requiring a cloud database.

## Reading Statuses

Each book can have one of the following statuses:

1. Want to Read
2. Reading
3. Finished

## Empty Reading List

When no books have been added, the application displays:

> Your reading list is empty. Add your first book.

## Technology

The application will use the web technologies selected during development in Bolt AI. Its data will remain browser-based.

## Project Goals

The goal of this project is to build a simple and user-friendly reading tracker while practising application development, debugging, Git version control, GitHub collaboration, and deployment.

## Future Improvements

Planned development stages may include:

- Preventing duplicate book titles.
- Limiting book titles to 60 characters.
- Adding a Delete button to each book card.
- Displaying summary counts for total books, currently reading, and finished books.

These improvements will be documented as they are implemented and tested.
